🚀 INICIO RÁPIDO
═══════════════════════════════════════════════════════════════════════════

1. Obtén tu API Key:
   https://platform.deepseek.com/api_keys

2. Configura el proyecto:
   cp .env.example .env
   # Edita .env y agrega tu API Key

3. Ejecuta la aplicación:
   
   Windows:
   run.bat
   
   macOS/Linux:
   ./run.sh
   
   O manual:
   python -m venv venv
   source venv/bin/activate  # o venv\Scripts\activate en Windows
   pip install -r requirements.txt
   streamlit run app.py

4. Abre en tu navegador:
   http://localhost:8501

📝 FLUJO DE TRABAJO
═══════════════════════════════════════════════════════════════════════════

1. Usuario carga CV actual
2. Usuario pega descripción de empleo
3. Streamlit envía ambos a DeepSeek API

5. App valida con Pydantic
6. DocumentGenerator crea Word y PDF
